# Course production walkthrough

**Live site:** https://aidacarlon01.github.io/course-production-walkthrough/

An interactive walkthrough of a Canvas course-production workflow supported by five
Claude Agent Skills — from checking the course setup to reviewing the completed
build. A companion to the case study *Creating AI agents for course production*.

Visitors follow a fictional module (FCA_DA_101 · Module 3 — Communicating with data)
through five stages — setup review, Canvas build, video placement, feedback actions,
and build review. Each stage shows the input, the task, a sample output, and the
checks involved, including where human judgement remains essential.

**Everything is fictional and illustrative.** Nothing on the site connects to Canvas,
Wistia, BugHerd, or any production system.

The site is a single self-contained `index.html`, served via GitHub Pages.

See also: the [interactive pattern catalogue](https://aidacarlon01.github.io/interactive-catalogue/).
